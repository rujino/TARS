# Miu (미우) 캐릭터 이미지 에셋 가이드

발랄하고 재치 있으며 활력 넘치는 수행 메이드 '미우'의 실시간 인터랙션 상태별 전신 일러스트 에셋 디렉터리입니다.

## 📁 권장 파일 명칭 및 규격

| 파일명 | 상태 키 (`state`) | 연출 및 포즈 가이드 |
|:---|:---|:---|
| `idle.png` | `idle` | 기본 대기 생기발랄한 스탠딩 포즈 |
| `thinking.png` | `thinking` | 고개를 살짝 갸우뚱하며 호기심 있게 생각하는 포즈 |
| `tool_use.png` | `tool_use` | **클립보드를 한 손에 끼고 재빠르게 태블릿이나 도구를 다루는 포즈** |
| `speaking.png` | `speaking` | 활기차게 웃으며 적극적으로 대화하는 포즈 |
| `interrupted.png` | `interrupted` | 유저의 Barge-in(말끊김)에 토끼 눈으로 깜짝 놀라는 표정 |

## 🎨 이미지 권장 사양
- **포맷**: PNG (투명 배경 필수, Alpha Channel 유지) 또는 WebP
- **해상도/비율**: 세로형 전신 일러스트 (권장 해상도: 최소 `800 x 1600` 이상, 종횡비 약 `1:2` ~ `1:2.5`)
- **앵커 정렬**: 바닥선(발끝) 기준 수직 정렬 (`object-position: bottom center`)
