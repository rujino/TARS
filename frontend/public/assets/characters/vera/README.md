# Vera (베라) 캐릭터 이미지 에셋 가이드

우아하고 차분하며 지적인 메이드장 '베라'의 실시간 인터랙션 상태별 전신 일러스트 에셋 디렉터리입니다.

## 📁 권장 파일 명칭 및 규격

| 파일명 | 상태 키 (`state`) | 연출 및 포즈 가이드 |
|:---|:---|:---|
| `idle.png` | `idle` | 기본 대기 차분한 스탠딩 포즈 |
| `thinking.png` | `thinking` | 턱에 손을 얹고 지적으로 고민/생각하는 포즈 |
| `tool_use.png` | `tool_use` | **메모보드/클립보드를 들고 펜으로 꼼꼼히 적거나 확인하는 포즈** |
| `speaking.png` | `speaking` | 입을 열고 정중하게 설명하며 대화하는 포즈 |
| `interrupted.png` | `interrupted` | 유저의 Barge-in(말끊김)에 살짝 놀라며 멈칫하는 표정 |

## 🎨 이미지 권장 사양
- **포맷**: PNG (투명 배경 필수, Alpha Channel 유지) 또는 WebP
- **해상도/비율**: 세로형 전신 일러스트 (권장 해상도: 최소 `800 x 1600` 이상, 종횡비 약 `1:2` ~ `1:2.5`)
- **앵커 정렬**: 바닥선(발끝) 기준 수직 정렬 (`object-position: bottom center`)
